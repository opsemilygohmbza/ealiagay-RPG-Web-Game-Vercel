# 🖋️ La Pluma de Miguel - Videojuego Web

Este proyecto es un videojuego de rol (RPG) diseñado para navegadores, centrado en la narrativa y la experiencia de usuario. Destaca por un flujo de trabajo que integra el diseño creativo con herramientas de despliegue moderno.

## 🚀 Aspectos Técnicos y Deployment
A diferencia de los proyectos convencionales de motores de juegos, este repositorio demuestra habilidades de integración y publicación web:
* **Core:** Basado en **JavaScript** para la lógica de eventos, gestión de variables y manipulación de datos.
* **Deployment:** Pipeline de despliegue continuo configurado en **Vercel** para asegurar alta disponibilidad y accesibilidad web.
* **Optimización:** Adaptación de recursos multimedia y scripts para minimizar tiempos de carga en entornos de navegador.

## 🕹️ Mecánicas e Ingeniería de Software
* **Lógica Programática:** Implementación de sistemas de variables dinámicas y switches para el progreso de la historia y eventos interactivos.
* **Interfaz de Usuario (UI/UX):** Adaptación de controles táctiles y de teclado mediante scripts personalizados para mejorar la jugabilidad en web.
* **Arquitectura de Proyecto:** Estructura de archivos organizada, facilitando el mantenimiento y futuras escalabilidades del motor.

## 🛠️ Instalación para Desarrolladores
1. Clona el proyecto: `git clone https://github.com/ealiagay/RPG-Web-Game-Vercel.git`
2. Ejecuta un servidor local (ej. Live Server de VS Code) y abre el archivo `index.html`.
